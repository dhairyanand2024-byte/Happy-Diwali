# One Night, Many Ages — The Return of the Light
`npm install && npm run dev` · `npm run build` · deploy on Vercel (framework preset: Vite).
Personalise: `/?to=Name&from=Name&wish=Text` (add `late=0` to hide the belated line).
Art is code-drawn placeholder SVG/CSS; audio in `src/assets/audio` is your supplied tracks (trimmed to 80s loops).
